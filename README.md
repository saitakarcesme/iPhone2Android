# iPhone2Android

iPhone ekranına Samsung Android telefon ve tabletlerden erişmek için başlatılan proje.

Hedef deneyim: ana ekrana eklenebilen bir web uygulaması, QR kodla eşleştirme ve iPhone'a tabletten erişim.

Proje şu anda teknik fizibilite aşamasındadır. Henüz çalışan bir ekran aktarımı veya uzaktan kontrol uygulaması içermez; kilitli iPhone'un Android üzerinden kontrolü doğrulanmış bir özellik değildir.
